# dariapavlova.me

Editorial portfolio for Daria Pavlova, a data engineer working across large-scale data infrastructure, search, semantic systems and applied AI.

## Stack

- Astro
- TypeScript
- Tailwind CSS
- Cloudflare Pages

## Development

```sh
npm install
npx astro dev --background
```

Use `npx astro dev status`, `npx astro dev logs`, and `npx astro dev stop` to manage the background server.

## Build

```sh
npm run build
```
